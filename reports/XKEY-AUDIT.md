# Historical source audit

This report records an early architecture review from the 0.1 development
stage. It is retained for project history; the current source inventory,
provenance and license decisions are documented in `THIRD_PARTY_NOTICES.md`,
`THIRD_PARTY.md` and `SECURITY.md`.

The current VKey runtime uses an InputMethodKit host, a bounded in-memory
conversion session and local Unicode rules. Network, clipboard, logging,
global keyboard monitoring, persistent typing history and external services
are not part of the production input path. The related source-level checks
are generated by `scripts/audit.sh` and are supplementary verification, not a
formal security certification.

VKey architecture: IMKServer → one IMKInputController per client session →
bounded in-memory Composer → direct replacement or standard marked text.
Backspace recomputes only the current word; Escape restores its raw spelling.
Committed words have no restoration history. Browser compatibility remains a
runtime test requirement because text clients can implement selection ranges
differently.
